# 🍶サービス概要
### お気に入りの日本酒を見つけよう！日本酒の検索・記録サービス
日本酒の味わいが書かれたタグを選ぶだけで好みに合った日本酒を検索できるサービスです。  
日本酒は写真やタグと一緒に記録でき、自分が飲んだ日本酒を見返したり、他ユーザーの記録を見ることができます。  
検索と記録から気軽に日本酒を探せます。

2. このアイデアはどこから生まれたか

2-1. きっかけとなった体験・感情
 
家でも美味しい日本酒が飲みたい！と思っていざお店に買いに行っても一体どんな味なのかイメージがつかなかったり、自分好みの日本酒はどれ？と迷走し、ラベルを眺めるだけで帰ってきてしまうことがありました。お店の人に聞く勇気はないし、調べるにもお店にある日本酒ひとつひとつ調べるのは面倒だと感じ、買うのをやめてしまうのは勿体無いので気軽に日本酒を調べるアプリがあったら便利だと感じた

2-2. なぜそれが「気になった」のか
   
・店員さんに気軽にお酒について聞ける性格ではないが、せっかく買うのだからテキトーに選んで失敗したくないという思いがあった

・お店によってはお酒ごとポップがついていてレビューが書いてあるものがあり、すべてのお店にあったらいいのにと感じた

3. 課題の整理

美味しい日本酒を選んで飲みたいのに何を選んだらいいか分からず困る

→ 気軽に日本酒の情報を得たい



-MVPで作る機能

・飲んだ日本酒を投稿する機能 → 銘柄名、タグ(既存のもの)、写真（任意）、メモ(任意)をつけて投稿する
      
・日本酒検索機能 → タグによる検索(まず4種類のタグを用意し、タグボタンを押すとタグづけされた投稿が表示される)
     
・投稿一覧機能 → 日本酒の写真が一覧で表示されてクリックすると詳細を見ることができる

-本リリースで作る機能

・レコメンド機能
   
・画像複数投稿機能
   
・銘柄を入力して検索できる機能
   
・投稿へのお気に入り機能

・タグの種類増やす

・Googleログイン
