# README
1. サービス概要
家でも美味しい日本酒が飲みたいけど何を選んだらいいのか分からない初心者に向けて、味わいタグを選ぶだけで日本酒を気軽に検索し、好みに合った日本酒を探せるサービス
---
 2. このアイデアはどこから生まれたか 
 2-1. きっかけとなった体験・感情
  家でも美味しい日本酒が飲みたい！と思っていざお店に買いに行っても一体どんな味なのかイメージがつかなかったり、自分好みの日本酒はどれ？と迷走し、ラベルを眺めるだけで帰ってきてしまうことがありました。お店の人に聞く勇気はないし、調べるにもお店にある日本酒ひとつひとつ調べるのは面倒だと感じ、買うのをやめてしまうのは勿体無いので気軽に日本酒を調べるアプリがあったら便利だと感じた

　2-2. なぜそれが「気になった」のか
   
　・店員さんに気軽にお酒について聞ける性格ではないが、せっかく買うのだからテキトーに　選んで失敗したくないという思いがあった
　・お店によってはお酒ごとポップがついていてレビューが書いてあるものがあり、すべてのお　店にあったらいいのにと感じた
  
---

 4. 想定ユーザーについて
　 4-1. 想定しているユーザー

年齢設定：
  - 年齢：20代
  - 理由：日本酒初心者が多く、日本酒選びに苦戦していることが予想されるため
生活・状況設定：
  - 生活・状況：日本酒初心者がお店で日本酒を購入するとき
  - 理由：他者の投稿から日本酒の情報を得て、日本酒の味をイメージしやすくなる
  - 　　　イメージが浮かぶことで買う際に日本酒を選びやすい
環境設定：
  - 環境：お店で日本酒について店員さんに聞く時
  - 理由：他者の投稿や自分の投稿から気に入った日本酒の写真を見せて、同じのもがある　　　　　のか、似たものはあるか聞くことができる
---

 4-2. 自分とユーザーの距離

- 自分自身
→ どんなタイプの日本酒が好みなのかは分かってきたが、具体的に気に入った銘柄があるわ　けではないので、お店で購入する際選ぶのが難しい。

 4-3. 実際に使われる可能性について(需要・存在確認)

　家でも美味しい日本酒が飲みたいけれど、日本酒は初心者で何を選んで買ったらいいのか分からない時、家や店頭で気軽に日本酒についての情報を得ることができる。インスタグラムやWEBサイトで調べると文章が長かったり、飲食店の情報など付随する情報が多かったりして、欲しい情報に辿り着くまでに時間がかかる。このアプリは日本酒に特化していて、検索もタグを選ぶだけで行えるため、短時間で欲しい情報が手に入り、日本酒を選ぶ際の手助けとなる。

 4-4. ユーザーがサービスを導入して利用するまでのイメージ(導入・継続の流れ)

日本酒を買いたいと思い立った時、このアプリを開く。家でゆったりとアプリを見るときには他者の投稿から感想を得て、自分の好みに近い日本酒を選んだり、飲んだことのない日本酒を見つけていつか飲んでみたいと想像を膨らませる。店頭でサクッと調べたいときには、検索ページからタグを選んで検索することで、自分の好みに合った日本酒を厳選して見ることができる。初回登録がなくても他者の投稿は閲覧できるようにすることで、どのようなアプリなのか目で見て体験できるようにする。その後、登録を行うことで日本酒の投稿や検索が行えるようになる。自分で飲んだ日本酒を投稿して、記録する楽しさや、気軽に検索して好みの日本酒を選べる便利さが継続の理由となると考えている。


 1. 既存サービス・競合調査

 5-1. 似たサービスの調査

- サービス名：飲みログ
- URL：https://app.nomi-log.jp/
- どんなことができるか：自分の飲んだお酒を記録し、振り返りや共有ができる。飲んだ頻度や摂取量を記録し、チャートやリストで確認できる。お酒を楽しめるスポットを検索できる。
---

 5-2. それでも自分が作りたい理由

既存サービスでは、他者の投稿がランダムで表示されている中から気に入った投稿を選び、クリックして詳細を見るしか日本酒の情報を得られない。大量の情報の中から好みの日本酒を探し出すのはかなり大変だと感じた。私は投稿を見るのではなく、好みの日本酒を探すのが目的だったため、検索機能がついたアプリが欲しいと思った。

 5-3. 差別化を一文で決める

- 私のアプリの差別化ポイント：タグを使って簡単に日本酒を検索できる
---

 1. このサービスで提供したい価値

 6-1. ユーザーの変化

・日本酒は大きな瓶でしか売っていない場合もあり、失敗したくないという思いが強いが、気　軽に情報収集できる場があることで好みの日本酒を見つけ、購入すること自体のハードルが　下がる
・アプリで日本酒の記録をまとめることで情報を見返しやすい
・様々な日本酒があることを知り、他のものも試してみたくなる

 6-2. 価値を一文で表す

このサービスは日本酒初心者が気軽に日本酒を探すことのできるサービス

 7. このアプリで実現すること

 MVPで作る機能
 ・飲んだ日本酒を投稿する機能
 　→写真・日本酒の名前・タグ付(既存のもの)・メモ(任意)をつけて投稿する
 ・日本酒検索機能
 　→タグによる検索(まず4種類のタグを用意し、タグボタンを押すとタグづけされた投稿が　　表示される)
 ・投稿一覧機能
 　→日本酒の写真が一覧で表示されてクリックすると詳細を見ることができる

 本リリースで作る機能
 ・レコメンド機能
 ・ユーザーがタグを作ることができる機能
 ・銘柄を入力して検索できる機能
 ・投稿へのいいね、お気に入り機能

 8. このアプリの懸念点とその対策

　　タグが少ないので日本酒を探す際にたくさんの投稿が表示されて見づらい
　　→複数のタグを選択できるようにすることで絞り込めるようにする

 9. 今後の展開・発展の方向性

・記録が溜まることで自分の好みの傾向がわかるようになる。また、他者の投稿を見ることで新しい日本酒を見つけ、飲んでみたいという意欲につながる
・銘柄検索など検索機能を充実させることでより探しやすくる
・たくさん投稿することで記録が溜まると、おすすめの日本酒を教えてもらえる
